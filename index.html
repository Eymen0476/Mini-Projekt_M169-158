Modul 169 / 158 – Container & Cloud

Mini-Projekt
Webserver

Deployment eines NGINX-Webservers via Docker in der AWS Cloud. Erstellt von Eymen Sarikaya im Rahmen des Moduls Vertiefung Container / Cloud.

Technologie-Stack

🐳

Docker / NGINX

Eigenes Docker-Image basierend auf NGINX:alpine. Webseite wird auf Port 8080 bereitgestellt.

☁️

AWS Cloud

Container läuft in der AWS-Umgebung. Erreichbar über öffentliche IP / DNS-Adresse des Hosts.

📁

Lokale Volumes

HTML/CSS-Dateien und Logdaten befinden sich in lokalen Verzeichnissen und werden via Volume gemountet.
